# 知简标识

以梦幻助手图标的书法风格为参考，重新绘制“知简”双字，以浅色细边框围成长方形。图形为原创 SVG 路径，不依赖字体或外部图片。

## 站点在用

- `logo.svg`：朱红“知简”，浅色边框，透明背景。首页标题与分享卡都引用它。
- `og.png`：1200 × 630 分享卡，Open Graph 与 Twitter 卡片共用。改标识或站点文案后重新生成。
- `../favicon.svg` / `../favicon.ico`：朱红底、米白单字“知”，适配小尺寸。
- `../apple-touch-icon.png`：180 × 180，不透明（iOS 会忽略透明通道，透明底会变黑）。

## 备用稿

PNG 导出与米白版本不进构建，源文件放在 `assets/brand/`：`logo.png`、`logo-paper.svg`、`logo-paper.png`。需要时再拷回 `public/brand/`。

SVG 画布为 440 × 240，PNG 宽度 1024 像素，按比例导出；ICO 包含 16、24、32、48、64、128、256 像素。边框 `#D8D6CC`，纸色 `#F4F1EA`，朱红 `#A44631`。
