# 知简标识

以梦幻助手图标的书法风格为参考，重新绘制“知简”双字，以浅色细边框围成长方形。图形为原创 SVG 路径，不依赖字体或外部图片。

- `logo.svg` / `logo.png`：朱红“知简”，浅色边框，透明背景，适合浅色页面。
- `logo-paper.svg` / `logo-paper.png`：米白“知简”，浅色边框，透明背景，适合深色背景。
- `../favicon.svg` / `../favicon.ico`：朱红底、米白单字“知”，适配小尺寸。

Logo 的 SVG 画布为 440 × 240，PNG 宽度 1024 像素，按比例导出；ICO 包含 16、24、32、48、64、128、256 像素。

边框 `#D8D6CC`，纸色 `#F4F1EA`，朱红 `#A44631`。
