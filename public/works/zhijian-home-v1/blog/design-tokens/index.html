用一份设计令牌统一全站的颜色

颜色不写死在任何组件里。朱砂、宣纸、墨色三层语义变量往下铺，换主题时整页跟着换。

前端 CSS 设计令牌 发布于 2026 年 6 月 18 日 更新于 2026 年 7 月 2 日

这套站点的底面是三样东西：朱砂、宣纸和墨。听上去像一句口味描述，落到代码里其实只是一组十六进制值。麻烦的地方从来不是选色，而是让同一个「朱砂」在按钮、下划线、当前项里都指向同一处，并且换到暗色时不至于把整页推翻重来。

三层，不要一层

最省事的写法是建一层变量，把 --red: #a3262a 这样的名字铺出去。它第一天就撑不住：暗色模式下这块朱砂要变浅，但「变浅的朱砂」和「正常的朱砂」是两个不同的决定，一个名字装不下两个决定。

所以这里分成三层，从下往上：

  • 调色板：纯客观的色值，带色阶编号，比如 --color-cinnabar-600。它只回答「这个颜料是什么颜色」。
  • 语义：回答「这块地方是干什么的」，比如 --action-primary。它不关心具体是哪个颜料。
  • 组件：只消费语义层，不许直接翻调色板。

判断标准很简单：把暗色模式整套删掉，语义层不应该有任何一行需要改。如果改了，说明语义层里混进了颜色决策。

调色板只写一次

朱砂取了四档，宣纸取了七档，墨色取了四档。档位数不是凑整，是按实际用到的地儿定的：纸要区分页面、抬起、凹下、强调四个层次，所以纸是四档起步。 

:root {
  /*== 朱砂 ==*/
  --color-cinnabar-300: #f58f87;
  --color-cinnabar-400: #de5d5b;
  --color-cinnabar-600: #a3262a;
  --color-cinnabar-700: #872126;

  /*== 宣纸 ==*/
  --color-paper-0: #fffefa;
  --color-paper-50: #fdfbf6;
  --color-paper-100: #f9f4ea;
  --color-paper-150: #f5ede1;
  --color-paper-300: #dfcfbb;

  /*== 墨色 ==*/
  --color-ink-500: #73685d;
  --color-ink-900: #211d18;
  --color-ink-950: #17130f;
}

语义层承担明暗

明暗切换只发生在语义层。媒体查询里重新赋值的是同一批变量名，组件的样式表一个字都不用动： 

:root {
  --surface-page: var(--color-paper-50);
  --text-primary: var(--color-ink-900);
  --action-primary: var(--color-cinnabar-600);
  --image-brightness: 1;
}

@media (prefers-color-scheme: dark) {
  :root {
    --surface-page: var(--color-ink-950);
    --text-primary: var(--color-paper-50);
    --action-primary: var(--color-cinnabar-400);
    --image-brightness: 0.7;
  }
}

注意最后那行 --image-brightness：水墨背景图在暗色下直接压到 0.7 倍亮度，而不是另做一张图。一张图配一个变量，比准备两套图省事得多。

为什么朱砂在暗色下要变浅

#a3262a 压在纸色上对比度足够，压在墨色上就糊成一团。所以暗色档换到 #de5d5b，同时把「朱底上的字」从纸色换成更深的墨——同一块朱红，两种底色下的文字颜色是相反的。

叠色用 color-mix，不新增变量

半透明的朱砂底、六成的分隔线、八成的浮层，都不单独定义新变量，而是在用的时候混出来。这样调色板不会随着页面增长而膨胀。 

.tag--primary {
  background: color-mix(in srgb, var(--action-primary) 10%, transparent);
  color: var(--action-primary);
}

.status {
  border-color: color-mix(in srgb, var(--border-default) 60%, transparent);
}

三条落地约定

  1. 组件样式表里出现十六进制值，一律算错；要新颜色就先回语义层加。
  2. 语义变量名里不出现颜色词，只出现用途词（surface、action、border）。
  3. 每加一个语义变量，同时写下暗色值；缺暗色值比写错色值更麻烦。

实测量化

这套令牌目前覆盖四种表面、两套明暗，一共 24 个语义变量。把变量换成人眼可读的对照，大概是这样：

语义变量 明色取色 暗色取色 用在哪
--surface-page 纸 50 墨 950 整页底
--surface-muted 纸 100 墨 900 名片底、引用块
--action-primary 朱砂 600 朱砂 400 当前项、链接、主按钮
--border-default 纸边 墨边 分隔线、卡框

最后一条经验：令牌不是设计系统。它只保证同一件事在不同地方长得一样，保证不了这件事本身对不对。真正决定这个站点像不像「朱砂配宣纸」的，是那些没人写进变量的地方——0 圆角、1px 线、衬线标题和竖线。
