SIMPLEBLOG · DESIGN LANGUAGE

V1

纸白与涟漪

SimpleBlog 是耶温的个人博客。界面的底子只有纸白与细线：页底 #fafafa， 40px 一格的低对比网格铺满整屏，正文用系统无衬线的 390 字重，层级全部靠字号、字距与留白拉开。 全站的灰阶只有七档，强调用的就是最深的那枚墨。 下面把它的色、字、底纹与控件拆开摆出来，供对照，不是另起的一套视觉。

  • 一档灰，一枚墨 七个颜色值全是灰阶，强调色不引入第二个色相。
  • 层级靠字号与留白 字重几乎只有 390 与 400，正文里最多用 500 标一处重点，不靠色块或阴影分层。
  • 结构是一根发丝线 分区用 1px #e5e5e5，网格压到 1% 黑，阴影只留给浮动的那一枚。

01

COLOR

七枚颜色，一条从纸白到墨黑的直线

原站的颜色变量只有七个值，全部集中在 styles/variables.css。它们不构成色板， 而是一条从纸白到墨黑的直线：越往右对比越强，越往左越像纸。强调色没有另开色相， 取的是这条线上最深的那一枚；连分线用的 #e5e5e5 也在这条线上。

纸 · 弱 墨 · 强
  1. 纸白 #FFFFFF 卡面、浮层、抽屉底 1.05 对页底
  2. 页底 #FAFAFA 整页底色，网格画在它上面 1.00 基准
  3. 分线 #E5E5E5 1px 分隔、空闲格与滚动条 1.2 仅作线
  4. 标注 #999999 日期与计数，原站取这枚 2.7 不足
  5. 次要 #666666 说明、副标题与图标 5.5 AA
  6. 正文 #3A3A3A 标题、正文与可点文字 10.9 AAA
  7. 强调 #1A1A1A 链接、当前项与悬停底线 16.7 AAA

「标注」那枚 #999999 对页底只有 2.7，原站拿它写日期与计数。 本页把同位置的日期改用 #737373（4.5，刚过 AA），其余照原值不改配色； 列表里的色块按原值渲染，所以它的读数仍低于 4.5，这是原站的选择，不是本页的。

02

TYPE & SPACE

字号七档，字重 390 与 400

字号从 0.75rem 到 1.875rem 一共七档，行高 1.6 到 1.8，正文段落按 1.8 排。 真正让这套界面安静下来的是字重：正文与控件一律写 390，标题才用 400， 两档之差几乎看不出来，也再没有第三档用来强调。这需要可变字体或支持任意字重的系统字体才生效， Windows 上的雅黑与 Segoe UI 会把它吸附到 400，所以本页也如实写 390—— 支持的环境细一分，不支持的环境退回常规，不额外补粗体。层级因此只能靠字号与留白拉开。

03

TEXTURE

三层底纹：网格、涟漪、雪

整页铺一张 40px 的方格纸，线是 1% 的黑；方格之上是一个 canvas，随机落墨， 涟漪由三圈不同半径的渐变环组成，越往外越淡。再往上是可选的雪花层。 三层都不参与布局，只挂在 position: fixed 的伪层上。

40px 一格 · 说明页把线提到 3.8% 以便看清
网格 background-image: linear-gradient(rgba(0,0,0,.01) 1px, transparent 1px), linear-gradient(90deg, rgba(0,0,0,.01) 1px, transparent 1px); background-size: 40px 40px;
涟漪 radial-gradient 描边 · 生命 280–420ms · 透明度 0.08–0.18 · 每次 2–4 环
雪 canvas 六臂描边，随机初速与横向漂移，pointer-events: none
毛玻璃 backdrop-filter: saturate(180%) blur(20px)

上面的控制坞可以切网格尺寸与动效；涟漪层会跟着整页走，鼠标划过也会带出一圈。
