## 设计思想

[耶温博客](https://github.com/zhijian521/SimpleBlog) 是一个 React + Markdown 的个人博客。它的界面几乎不「设计」：页底是 `#fafafa`，上面铺一层 1% 黑的 40px 方格纸，正文用系统无衬线、字重 390，全站只有一根 1px 的 `#e5e5e5` 分线。

三条约定撑起这套极简：

- **一档灰，一枚墨。** 令牌里七个颜色值全是灰阶，从纸白到近黑排成一条直线，主界面只用这七档。强调色不另开色相，取的就是这条线上最深的那枚 `#1a1a1a`。例外只有两处，都不在令牌里：错误边界自带一组紫蓝，雪片层自带五种浅蓝，各自写死在组件内。
- **层级靠字号与留白。** 字号七档（其中 `lg` 只服务正文小标题 `h4`）、间距六档。正文与控件写 390、标题写 400，只有正文强调与表头用 500，200 与 600 仅出现在错误页。没有色块、没有卡片阴影、没有渐变。
- **动效是氛围，不是装饰。** 底层 canvas 随机落墨、鼠标划过带出涟漪，可切雪花；两者都在 `position: fixed` 的伪层上，不参与布局，也不挡点击。

## 还原范围

- **令牌全量复现**：七个颜色、六档间距、七档字号、行高 1.4–1.8（body 1.6、正文段落 1.8）、字重 390、圆角 2/4/6/12px。组件样式表里不出现十六进制值，色板的色块也统一取令牌变量。
- **五个章节**：色板（色阶条 + 逐行读数）、字与距（六档样张 + 六段间距实宽）、底纹（网格、涟漪、雪、毛玻璃四道配方）、控件、模块。全部用 HTML 与令牌现画，**不含任何截图**。
- **控件层**：文字按钮（hover 铺 4% 黑、底线从中向两侧展开）、树形目录（分组折叠、当前项左侧 2px 墨线与 2px 位移）、搜索输入与标签、贡献格五级色阶、加载中的五道短线、毛玻璃浮动按钮展开组。
- **原站的涟漪参数照搬**：生成间隔 600–1500ms、生命 280–420 帧、透明度 0.08–0.18、每次 2–4 环、鼠标移动阈值 80px。控制坞可以切 40px／20px／关三档网格、涟漪／雪／关三档动效，切到「关」会停掉 rAF 并清空画布。
- **三张版面**（首页、文章页、搜索面板）都是把上述控件拼起来，文案取自原站的真实文章《关于我》《AICoding 使用与推荐》《Git 提交规范》，读数为示例数据。原站的数据来自本地 Markdown 文件，无法直接静态嵌入，所以这里做的是设计语言的静态还原。
- 正文小字比原站深一档：原站用 `#999999` 写日期与计数，对页底只有 2.7，本页同位置改用 `#737373`（4.5，刚过 AA）。色板里仍按原值渲染并标出原读数，不擅自改配色。
- 无脚本时章节、色板、版面示意照常可读；目录折叠、控制坞与涟漪需要 JS。`prefers-reduced-motion` 下动效默认关闭。
